Since leaves beta as a free, open-source app. Every feature works without a key, trial or account, and the code is on GitHub under GPL-3.0-or-later. This release also opens repositories as tabs in one window, adds a Commits tab to Review, groups the commit menu into submenus and trims the shortcuts to the ones you use often.
