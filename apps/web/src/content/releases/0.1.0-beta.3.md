Beta 3 replaces refusals with fixes. When an action can't run because of the branch you're on, uncommitted changes, a rejected push or a pull request GitHub won't merge, the app states the reason, offers the fix, and runs both as one undo step. Stacks in Review get a header with their status and a merge action, and pull requests switch between draft and ready in place.
